# Seerr on pc6 CT109

Seerr is the maintained successor to Overseerr and Jellyseerr. It runs on
`http://10.0.0.128:5055` and uses `/opt/seerr/config` in CT109 for persistent
configuration.

The initial configuration is migrated from the stopped Tower Overseerr instance.
The old Tower appdata must remain in place until Seerr has been verified with
Emby, Sonarr and Radarr.

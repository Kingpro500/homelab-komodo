🔫 Regler for denne siden (homelab-komodo · docs/network-map)
• ALLE endringer lagres i EGEN versjon, selv om det bare er én ting som endres — tilfeldige AI-boter glemmer dette hele tiden. Trykk på versjonsnummeret överst til høyre for historikken og lagringsmåten.
• På hver versjon må det noteres i versions/index.html hva som faktisk endret seg (oppsummering av endringene), og forrige versjon flyttes til versions/vNNN/ så den aldri slettes.
• Node-sammendraget øverst (fire maskiner med CPU/RAM/Disk + grønne strøm-tall) er PÅLAGT og må aldri fjernes — det hentes fra CT157 /nodes. Se «⬆ PÅLAGT» i README.
• Statuslys + av/på-knapper: POST /control på CT157 med AUDIT_TOKEN; token lagres i nettleserens localStorage (feltet skjules etter lagring, trykk ✎ for å endre).
• Videostrømmer telles fra CT157 /streams (Tunarr + Emby) — det er de store grønne tallene på maskinkortene.
• Hele regelsettet ligger i repoet homelab-komodo → docs/network-map/README.md (vedlikehold), og serverlogikken i ~/.hermes/scripts/servicemap_*.py på CT157.
